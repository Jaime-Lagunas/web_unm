====================================================================
SITIO WEB EDUCATIVO DE 3 PÁGINAS: CAFETERÍA "AROMA Y GRANO"
Integración de Tema 5 (jQuery) y Tema 6 (jQuery UI)
====================================================================

ARCHIVOS DEL SITIO:
1. index.html              -> Barra de navegación, Hero con slideToggle(),
                              sección de servicios con Widget Tabs, animaciones
                              de color (.animate) y efecto shake (.effect), e
                              interacción Draggable + Droppable para armar un combo.
2. menu.html               -> Buscador con Widget Autocomplete + filtro en vivo
                              (keyup), tarjetas de bebidas, lista reordenable
                              (Sortable), acordeón de preguntas frecuentes
                              (Widget Accordion) y botón flotante de WhatsApp.
3. reservas-contacto.html  -> Formulario de reserva con Widget Datepicker +
                              envío asíncrono AJAX POST ($.post), consulta AJAX
                              GET ($.ajax), mapa embebido de Google Maps y
                              botón de WhatsApp.
4. estilos.css             -> Hoja de estilos compartida entre las 3 páginas.

CÓMO EJECUTARLO:
- Abre 'index.html' en tu navegador web (con conexión a internet para
  cargar jQuery 3.7.1, jQuery UI 1.14.1 y el mapa de Google Maps).
- Usa la barra superior para navegar libremente entre las 3 páginas.
