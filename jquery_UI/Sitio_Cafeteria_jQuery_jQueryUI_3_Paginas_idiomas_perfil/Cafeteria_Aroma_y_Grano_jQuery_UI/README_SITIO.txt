====================================================================
SITIO WEB EDUCATIVO DE 3 PÁGINAS: CAFETERÍA "AROMA Y GRANO"
Integración de Tema 5 (jQuery), Tema 6 (jQuery UI), Perfiles y Traducción
====================================================================

ARCHIVOS DEL SITIO:
1. index.html              -> Hero con slideToggle(), Widget Tabs, animaciones
                              de color (.animate), efecto shake (.effect) e
                              interacción Draggable + Droppable.
2. menu.html               -> Buscador con Widget Autocomplete + filtro en vivo
                              (keyup), tarjetas de bebidas, lista reordenable
                              (Sortable), acordeón (Widget Accordion) y WhatsApp.
3. reservas-contacto.html  -> Formulario con Widget Datepicker + envío AJAX POST
                              ($.post), consulta AJAX GET ($.ajax), mapa de
                              Google Maps y botón de WhatsApp.
4. estilos.css             -> Estilos compartidos y variables CSS para perfiles
                              de color y tipografía.
5. perfiles-traductor.js   -> Botones en barra para cambiar perfil de color,
                              tipo de fuente y traducir entre ES, EN y FR (con
                              comentarios sobre librerías gratuitas).
