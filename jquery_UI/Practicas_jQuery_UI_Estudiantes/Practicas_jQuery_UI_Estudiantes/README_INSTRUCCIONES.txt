¡Hola! Bienvenida y bienvenido a tu carpeta de prácticas de jQuery UI.

¿CÓMO USAR ESTOS ARCHIVOS?
1. Cada archivo .html es una página web completa y funcional.
2. Para ejecutarlos, simplemente haz doble clic sobre cualquier archivo
   .html y se abrirá automáticamente en tu navegador web (Chrome,
   Edge, Firefox, Safari).
3. Asegúrate de tener conexión a internet para que se carguen las
   librerías oficiales de jQuery y jQuery UI desde el CDN.
4. Abre los archivos en tu editor de código favorito (VS Code,
   Sublime Text, etc.) para leer los comentarios paso a paso,
   modificar valores y experimentar por tu cuenta.
