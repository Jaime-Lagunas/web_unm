====================================================================
SITIO WEB EDUCATIVO DE 3 PÁGINAS: CAFETERÍA "AROMA Y GRANO"
Integración de Tema 5 (jQuery), Tema 6 (jQuery UI), Perfiles y Google Translate
====================================================================

ARCHIVOS DEL SITIO:
1. index.html              -> Hero con slideToggle(), Widget Tabs, animaciones
                              de color (.animate), efecto shake (.effect) e
                              interacción Draggable + Droppable.
2. menu.html               -> Buscador con Widget Autocomplete + filtro en vivo
                              (keyup), tarjetas de bebidas, lista reordenable
                              (Sortable), acordeón (Widget Accordion) y WhatsApp.
3. reservas-contacto.html  -> Formulario con Widget Datepicker + envío AJAX POST
                              ($.post), consulta AJAX GET ($.ajax), mapa de
                              Google Maps y botón de WhatsApp.
4. estilos.css             -> Estilos compartidos, variables CSS para perfiles
                              de color y tipografía, y estilos del widget de
                              Google Translate.
5. perfiles-traductor.js   -> Botones en barra para cambiar perfil de color,
                              tipo de fuente y función de inicialización del
                              Widget Gratuito de Google Translate (ES / EN / FR).

NOTA SOBRE LA TRADUCCIÓN CON GOOGLE TRANSLATE:
- Cada página incluye el script oficial gratuito de Google Translate:
  https://translate.google.com/translate_a/element.js?cb=googleTranslateElementInit
- Al seleccionar Inglés o Francés en el selector de la barra superior,
  Google traduce automáticamente TODO el contenido textual de la página
  completa (navegación, títulos, párrafos, tarjetas, botones y pie de página).
